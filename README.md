# 카페인 기전 지도

카페인(1,3,7-trimethylxanthine)이 각성, 수면 방해, 심박 변화, 혈압 상승, 손떨림, 통증 변화 같은 생리 반응을 일으키는 과정을 아데노신 수용체 길항에서부터 따라가 보는 교육용 인터랙티브 프로그램입니다.

## 실행

빌드 과정이 없는 단일 HTML 파일입니다. `index.html`을 브라우저로 열면 됩니다. 글꼴은 Google Fonts에서 불러오고, 연결이 없으면 시스템 글꼴로 대신 표시됩니다.

## 구성

1. **노출 조건과 혈중 농도**: 하루 최대 3회 섭취, 체중, 섭취 습관, 개인 민감도, CYP1A2 요인(흡연, 경구피임약, 임신, CYP1A2 억제제), 수면 부족, 진통제 병용을 입력합니다. 혈중 농도 곡선, A1·A2A 점유 지수, 취침 시 체내 잔여량을 보여 줍니다.
2. **작용 경로 지도**: 약물 → 수용체 → 세포 내 신호 → 조직·회로 → 생리 반응의 5열 인과 그래프입니다. 노드를 누르면 상류·하류 경로가 강조되고 기전 단계, 주의점, 근거 등급, 참고문헌이 표시됩니다.
3. **예상 반응 카드**: 10가지 반응을 정성 단계(미미·약함·중간·뚜렷)와 근거 등급으로 보여 줍니다. 심박 변화는 올리는 힘(A1 억제 해제, 교감 반응)과 내리는 힘(압수용체 반사)의 균형으로 표시합니다.
4. **심화 탭**: 통증 4가지 상태, 금단 시간 경과, 고농도 실험 기전(PDE, RyR 등)의 연구 농도 비교, 약물 상호작용, 근거 등급과 참고문헌.

## 모델 가정

- 1구획 경구 흡수 모델: 흡수속도상수 3 h⁻¹, 분포용적 0.65 L/kg, 생체이용률 약 100%, 분자량 194.19
- 반감기: 기본 3.5 / 5 / 7시간 × 요인 배수(흡연 ×0.6, 경구피임약 ×1.8, 임신 후기 ×2.5, 중등도 억제제 ×1.5, 강한 억제제 ×6). 문헌 보고 범위를 반올림한 교육용 근사입니다.
- 점유 지수 = C / (C + Ki), Ki는 A1 12 µM, A2A 8 µM의 대표값입니다. 인간 수용체 Ki 보고값은 실험계에 따라 폭이 넓습니다(A2A는 약 2–23 µM).
- 내인성 아데노신과의 경쟁, 단백 결합, 활성 대사체 paraxanthine, 전날 섭취분의 누적은 반영하지 않습니다. 곡선은 모체 카페인만 계산합니다.
- A2B·A3는 일상 섭취에서 개별 증상에 대한 기여가 불확실해, 점유 지수를 숫자로 표시하지 않습니다.

## 설계 원칙

프로그램의 과학적 정확도를 위해 다음을 구분했습니다.

- **농도 구분**: 일상 섭취량의 A1·A2A 길항과, 고농도 실험에서만 의미가 있는 PDE 억제·RyR 활성화·GABA\_A 조절·MAO-A 억제를 별도 화면으로 분리했습니다. 일반 섭취 후의 각성, 불안, 손떨림을 고농도 기전으로 설명하지 않습니다.
- **직접과 간접**: 각성·빈맥·손떨림·통증을 모두 같은 교감신경 흥분의 결과로 묶지 않고, 수용체에서 직접 이어지는 경로와 카테콜아민을 거치는 간접·조건부 경로를 다른 선으로 그립니다. 카페인은 β수용체 효현제가 아닙니다.
- **방향이 정해지지 않은 결과**: 심박 변화는 A1 억제 해제·교감 반응(증가 방향)과 압수용체 반사(감소 방향)의 합으로 계산합니다. 통증은 단독 급성, 진통제 병용, 중단 후 금단, 수면 방해를 통한 간접 영향의 네 상태로 나눕니다.
- **cAMP 방향**: A1(Gi/o) 길항과 A2A(Gs/olf) 길항의 결과가 반대임을 그대로 표시합니다. 카페인이 모든 조직에서 cAMP를 올리는 것은 아닙니다.
- **근거 등급**: A(사람 임상 연구로 확인), B(사람 연구가 있으나 가변적), C(기전 근거는 있으나 인체 결과 불확실), D(주로 고농도 세포·동물 실험)로 표시합니다. 이 프로그램을 위한 분류이며 GRADE 같은 공식 평가체계가 아닙니다.

## 범위와 한계

- 계산 범위는 일반 성인의 일상 섭취(하루 400 mg 이내, EFSA 기준)입니다. 고용량 섭취와 중독은 이 모델로 설명하지 않습니다.
- 반응 단계(미미·약함·중간·뚜렷)는 정성 지표입니다. 혈중 농도를 심박수, 떨림 강도, 통증 변화량으로 바꾸는 검증된 범용 공식은 없습니다.
- 개인의 혈중 농도나 증상을 예측하지 않습니다.
- 참고문헌 링크는 PubMed 또는 Google Scholar 검색으로 연결됩니다. 원문 서지는 연결된 검색 결과에서 확인하세요.
